# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or privilege escalation risk in `drakvuf-auto-installer`, please disclose it responsibly.

Do not open public GitHub issues for security vulnerabilities. Instead, contact the maintainer directly via GitHub or personal security contact.

Please include:
- A clear description of the vulnerability.
- Steps or proof-of-concept scripts to reproduce the issue.
- Potential impact on host isolation or hypervisor escape.

We appreciate your efforts to keep open-source security tools safe and reliable.
